# Vision

Build a modern cloud-ready ERP platform that can replace software such as Marg ERP, Busy, Vyapar and compete with ERPNext and Odoo for Indian wholesale and retail businesses.

The platform must be modular, scalable, API-first, mobile-ready and configurable.
